# Castle for iOS

The iOS client is a read-only Castle library reader. Its first vertical slice loads a bundled mobile snapshot generated by `castle-snapshot`; the repository boundary is intentionally abstract so a GitHub-backed implementation can replace the fixture next.

## Generate and open the project

```sh
xcodegen generate --spec apps/ios/project.yml
open apps/ios/CastleMobile.xcodeproj
```

## Refresh the bundled fixture

From the repository root:

```sh
cargo run --manifest-path native/Cargo.toml -p castle-snapshot -- build \
  --library examples/library \
  --repository . \
  --public apps/ios/CastleMobile/Resources/Fixture \
  --profile mobile-read-only
```

The checked-in fixture is sample content only. GitHub authentication, archive download, native bridge packaging, and cache refresh are the next implementation slice.
