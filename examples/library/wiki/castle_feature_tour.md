# Castle feature tour

This library is a hands-on tour. Open the linked examples instead of reading
the list as documentation.

## Library and Markdown

The [[notes/welcome|welcome note]] demonstrates headings, tables, code, task
lists, aliases, tags, and links. [[notes/design_principles|Design principles]]
has repeated incoming links, so its sidebar is a good backlinks example.

## Search and connections

Search for **serendipity**, **consent**, or **quiet corner**. Each term appears
across several sections. Then open [[wiki/graph_field_guide|Graph field guide]]
and switch between relation and “known from” grouping.

## Structured records

- People: [[people/alex_morgan|Alex]], [[people/amara_okafor|Amara]], and the full People section
- Projects: [[projects/neighborhood_atlas/neighborhood_atlas|active]], [[projects/mobile_story_booth/mobile_story_booth|planned]], [[projects/listening_garden/listening_garden|completed]], and [[projects/night_market_signage/night_market_signage|idea]]
- Tasks: todo, in progress, blocked, and done records with subtasks and deadlines
- Calendar: social and work events, a weekly series, project links, and a cross-midnight event

## Other workspaces

Open **Canvas** for a visual project map and **Sheets** for a small formula-based
Atlas tracker. The Playlists section demonstrates embedded video discovery,
while Shortcuts shows internal and external destinations grouped into tabs.

Return to [[notes/welcome|Welcome to the Neighborhood Atlas]] whenever you want
a fresh trail through the graph.
